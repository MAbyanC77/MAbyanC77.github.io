# Mohammed Abyan Chowdhury — Portfolio

Responsive personal portfolio built with plain HTML, CSS and JavaScript.

## GitHub Pages
1. Create a public repository named `MAbyanC77.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Your site will be available at `https://MAbyanC77.github.io`.
